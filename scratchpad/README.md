# scratchpad/

Local one-off digs and throwaway probes. Contents are gitignored (except this
README). Do not commit analysis scripts or mini data mirrors here — put
reusable tools in `tools/`, and keep authoritative tapes/reports under
`ai_reports/` on the machine that owns them.

`scratchpad/mini-pull/` (ignored) may hold temporary copies pulled from the
mini for analysis; delete when done so this tree stays clean.
