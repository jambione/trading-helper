# The standard desk (baseline set 2026-10-30)

The operator named this week's desk the new standard on 2026-10-30: "the new standard that we should be building off of to improve gaining profit and cutting losses. Solid ground to build off of."

Every change from here is judged against this desk. A change that can't show it beats this desk doesn't ship.

- **Config:** [config/baselines/standard_2026-10-30.json](../config/baselines/standard_2026-10-30.json). It's a copy of the mini's live `config/bot_config.json` on 2026-10-30 and is identical to the repo copy.
  - Config fingerprint: `9e0182784cab`, the same on every trade of the week.
  - Key settings:
    - empty-square entries only;
    - $20 floor;
    - 0.15% delayed-SIP spread cap;
    - 5 positions × 20%, risk 1.0%, slot equity 60;
    - %R trend 15 and the 5-minute slow veto;
    - slope-now gate off;
    - last entry 15:50, flatten 15:58;
    - market entry orders;
    - daily loss brake off (paper).
- **Code:** git tag `standard-2026-10-30`. The week ran on commits `874a7791` (Mon), `be84fb9b` (Tue), `10739727` (Wed) and `a34c473c` (Thu). The tag is the commit that holds this file. Live trading code is unchanged since Thursday's restart, apart from study tools and docs.

## How to use it

- **Replays and A/B tests** pin this config as REF.
- **Forward changes** are scored against this week's numbers, and against the standard's own forward record once it has more days.
- **New sessions extend the record.** Each session run on the standard config adds to it, so it grows from 4 days. If the config changes, the standard's record stops there and the new config starts its own.

## Caveat

Four days and 101 trades is a small sample. A −0.6 bp average can't yet be told apart from the −5 bp of the weeks before, and part of the improvement may be the market. The standard is a reference point to build from, not proof the desk is profitable.
